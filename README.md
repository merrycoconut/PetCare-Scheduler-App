# PetCare Scheduler App

## Overview

A simple, console-based Java app that manage and store each pet's activities. 

## Features

- Register their pets
- Log important appointments
- Track upcoming tasks
- Keep a history of past visits
- Storing information safely when the app closes

## Installation

1. Download the code to your local machine.
2. Compile the source files:
    
    ```bash
    javac com/app/*.java com/utils/*.java    
    ``` 

## Usage

Start the application:

```bash
java -cp . com.app.PetCareScheduler
```

## Technologies Used

- Java
